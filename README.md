# Shop

Persoonlijke boodschappenapp gekoppeld aan Sharon.

Nieuwe installatie zonder geïmporteerde Git-geschiedenis of persoonlijke catalogus. Gebruikers beheren hun eigen lijsten. De app bewaart automatisch lokaal; JSON-back-ups worden door de gebruiker gedownload. Delen via Sharon is een bewuste actie.

Website: https://stefan-van-dijk.github.io/shop/

Publiceren: zie PUBLISHING.md.

### Optioneel verbinden met Sharon
Shop blijft zelfstandig bruikbaar. Maak in Sharon → Notities en lijsten → Shop
verbinden een code en kopieer die. Druk in Shop op het Sharon-logo. Alleen bij een
passende code of benodigde toestemming verschijnt tijdelijk Koppelen met Sharon.
Na succesvolle koppeling verdwijnt dit item; verbinding beheren blijft beschikbaar.
Een bestaande koppeling wordt nooit automatisch vervangen.

De code heeft twaalf tekens en is zeven dagen geldig. Ophalen bindt de code aan
één Shop-sleutel; pas na lokaal opslaan en ontvangstbevestiging wordt de code
verwijderd en meldt Sharon de koppeling als geslaagd. Bij terugkeer in het open
Sharon-koppelscherm ververst de status automatisch. Lokale lijsten blijven privé.

Vereist Sharon 0.4.81 en bijbehorende server/connections.php op
https://sharon.life/log/api/connections.php. GitHub Pages uploadt dit bestand niet.
Behoud de bestaande configuratie en private opslag. Browsers kunnen toestemming
voor klembordlezen vragen; de app vraagt dit alleen na een bewuste klik.
